# 邮盘速达

给课程教材和课件做一个统一入口。老师发来的百度、夸克、阿里、123、蓝奏、悟空等网盘链接，以及未收录平台的链接，都可以保存为资料卡，按课程搜索。应用在本机保存资料名称、链接、提取码和备注；打开资料时进入网盘官方页面。

如果拿到了**可直接访问的文件地址**，下载页会检查 HTTP Range 支持情况。文件达到 2 MB 且来源支持范围请求时，最多使用 4 路分段传输；否则单路下载。可切换单路模式，用同一文件做速度对照。暂停或断线后，重新保存到原路径可继续传输。界面显示进度和本次平均速度。

## 运行

安装 Node.js 18+ 后，在项目目录执行：

```bash
npm install
npm start
```

Windows 可在安装依赖后双击 `启动邮盘速达.cmd`；当前工作区已有 Electron，可直接双击运行。

运行测试：`npm test`。运行本机限速源测速：`npm run benchmark`。Windows、macOS、Linux 均可通过 Electron 源码运行；目前还没有安装包。

## 使用

1. 在“资料库”粘贴分享文案，填资料名称和课程，保存资料卡。
2. 点击“打开网盘”，按平台正常流程获取资料。
3. 只有在拿到文件直链时，才到“下载加速”粘贴直链并开始下载。

普通网盘分享页不是文件直链。应用不会解析私人网盘接口，也不会绕过登录、会员或平台限速。分段传输是否提高实际速度取决于下载源与网络；可用同一文件与原平台下载方式比较。

## 技术说明

Electron 主进程负责文件与网络操作，界面通过隔离的 preload API 调用。下载文件先写入 `.part` 临时文件，分段下载时用 `.part.N` 和 `.parts.json` 保存进度，完成后再合并成目标文件。分段下载会校验服务端返回的 `Content-Range` 和各分段大小。下载中断后请选同一路径继续。

项目仅处理你有权获取和使用的课程资料。
