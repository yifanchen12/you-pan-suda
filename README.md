# 邮盘速达

把老师发在不同网盘的教材和课件按课程整理。粘贴分享文案后，应用识别链接与提取码；资料卡只保存在本机。

## 已有功能

- 课程资料卡、搜索和网盘筛选；未收录的网盘也可保存链接。
- 夸克分享链接可直接在应用内展开文件夹并下载，无须另开解析服务或网盘页面；使用夸克访客接口获取文件和下载地址。
- 其他网盘可接入 [NFD Parser](https://github.com/qaiu/netdisk-fast-download) 的接口。默认连接本机服务；社区服务须主动选择，并在发送分享链接和提取码前确认。
- 下载器选择：内置 4 路分段下载、[Gopeed](https://github.com/GopeedLab/gopeed) 本机 REST API、[GDownload](https://github.com/cool2528/GDownload) 本机 aria2 RPC。解析出的文件地址可直接交给所选下载器，无须从网盘页面再复制直链。
- 下载进度与速度；内置下载器支持暂停后选同一路径续传。外部下载器的文件存放位置由各自的设置决定。

NFD Parser、Gopeed 和 GDownload 都是**独立软件**，本仓库没有复制它们的代码或安装包。Gopeed 和 GDownload 的接口只接受本机地址；接口密钥仅在当前应用运行时使用，不写入资料卡或本地配置。

## 运行

安装 Node.js 18+ 后，在本目录执行：

```bash
npm install
npm start
```

Windows 安装依赖后也可双击 `启动邮盘速达.cmd`。运行测试：`npm test`。目前提供源码运行，尚无安装包。

## 使用

1. 打开应用后，在“下载加速”页粘贴老师发的分享链接，点击“查看文件”或“下载”。无需先保存资料卡。
2. 勾选需要的文件，点击“下载选中”。内置下载器只需选一次保存文件夹，随后依次下载；同名文件自动加序号，不覆盖已有文件。
3. 夸克分享可直接列出文件。其他网盘需先运行本机 NFD Parser，或主动选择社区解析服务；可解析的平台和文件由解析服务决定。
4. 文件直链也可粘贴到同一个输入框直接下载。Gopeed 须先开启本机 REST API；GDownload 须先启动并配置 aria2 RPC。外部下载器需自行安装。

应用每次打开默认使用内置下载器。若手动选择的 Gopeed 或 GDownload 本机接口未启动，下载时会切回内置下载器并让你选择保存文件夹。

夸克访客下载受平台限制，部分文件可能需要登录；本项目不读取登录 Cookie。GDownload 自带百度、阿里、夸克、123、蓝奏云等网盘插件；这些插件运行在 GDownload 内，本项目通过其 aria2 RPC 提交**文件直链**，不直接调用插件。悟空网盘等未列出的平台仍可存为资料卡，但不能保证直接解析。多连接能否提高实际速度，取决于网盘服务器、网络和账号权限；本项目不保证绕过平台限速。

## 本地数据与技术说明

资料卡保存在 Electron 用户数据目录的 `resources.json`，本项目没有服务器。内置下载器先写入 `.part` 临时文件，分段时使用 `.part.N` 和 `.parts.json` 记录进度，并校验 `Content-Range` 与分段大小。外部下载器使用自己的任务与文件管理。

项目仅处理你有权获取和使用的课程资料。
